## Data stewardship, eigen gebruik van Github

Voor het werken met R of andere code/scriptprogramma's, is het overzichtelijk en handig om direct te kunnen communiceren met de gemeenschap. Bijvoorbeeld door via Github code en script te delen, te laten aanpassen, maar ook het reproduceerbaar maken van het onderzoek. 

Deze punten zijn de redenen voor het gebruik van Github bij dit associatie-onderzoek:
- Het delen van protocols gebaseerd op de vorming van de BAM-bestanden, count matrix en gebruikte testen (reproduceerbaarheid). 
- Het gemakkelijk linken van literatuur binnen het eigen artikel, zonder extra tabbladen en downloads van directe PDF-bestanden (via hyperlinks). 
- Het structureel verdelen van de informatie voor het doelgericht zoeken.
